# 🚚 LogiDutra - front-end
> **Projeto Integrador (PIE-PM4)**  
> Sistema de gestão logística desenvolvido para a empresa de móveis **Dutra-Móveis** em Foz do Iguaçu.

---

## 📌 Sobre o Projeto

O **LogiDutra** é uma solução de gestão logística voltada para o setor moveleiro individual para o Dutra-Móveis. O sistema foi desenvolvido como projeto acadêmico do curso de **Análise e Desenvolvimento de Sistemas** da UniAmerica, focado em atender às necessidades operacionais através de regras de negócio essenciais, controle de romaneios, frotas, motoristas e entregas.

## 🛠️ Tecnologias Utilizadas

* **Frontend:** Angular, Bootstrap, SweetAlert2
* **Backend:** Java / Spring Boot
* **Linguagens:** TypeScript, HTML5, SCSS, Java

---

## 🚀 Funcionalidades Principais

- [x] **Cadastro e Gestão de Romaneios:** Criação, edição e listagem detalhada de romaneios de entrega.
- [x] **Controle de Produtos:** Adição e controle de quantidades de itens por romaneio.
- [x] **Gestão de Clientes:** Cadastro rápido (*inline*) de clientes com vinculação direta aos horários de entrega.
- [x] **Controle de Frotas e Motoristas:** Associação de veículos e motoristas responsáveis por cada rota.
- [x] **Painel Administrativo:** Controle de acesso diferenciado para administradores e usuários padrão.
